　橋本工業㈱ 金型製作原価管理システム
　新規PC セットアップ手順書
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ システムURL（ブラウザのアドレスバーにコピペ）
https://84stamp1-jpg.github.io/hashimoto-press/mold_cost_system.html

■ 推奨ブラウザ：Google Chrome

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順1】ブラウザでURLを開く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

上記URLをChromeのアドレスバーに貼り付けてEnterを押す。
※初回はFirebase未接続のため「接続エラー」が表示されますが正常です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順2】Firebase接続設定を入力する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

画面上部の「設定」タブをクリック
→「Firebase接続設定」に以下を入力：

　PROJECT ID
　hashimoto-press

　DATABASE URL
　https://hashimoto-press-default-rtdb.asia-southeast1.firebasedatabase.app

　API KEY（※下記参照）
　→ 【Firebase WebクライアントAPIキー。dantori_navi.html 等の
　　 firebaseConfig 内 apiKey を参照(公開リポジトリのため本書から除去)】

入力後「保存して接続」ボタンをクリック
→ 右上に「● Firebase接続済」と緑色で表示されれば成功


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順3】kintone設定を読み込む
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Firebase接続後、設定タブ → kintone連携設定 の下部にある

　「🔄 共有設定を再読込」ボタンをクリック

→「共有設定を読み込みました」と表示されれば完了
→ GASプロキシURL・App ID・フィールドコードが自動で設定される


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順4】動作確認
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

「ダッシュボード」タブを開いて金型一覧が表示されれば完了。

ブックマークに登録しておくと次回から便利です。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【API KEY の確認方法】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

設定済みのPCで以下を操作：
1. システムの「設定」タブを開く
2. Firebase接続設定 → API KEY欄をクリック
3. パスワード表示ボタン（目のアイコン）で表示してコピー

※API KEYは重要な情報のため、この手順書には記載していません。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【困ったときは】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・画面が真っ白 → URLを再確認してリロード（F5）
・Firebase未接続 → 手順2のAPI KEYを再確認
・データが表示されない → 手順3の「共有設定を再読込」を再実行
・kintone取込ができない → 設定タブ → 「🔍 フィールドコード確認」で確認
