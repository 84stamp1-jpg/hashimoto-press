## 2. 左右にグレーが出る理由（実測済み）

SVGの中身は横いっぱい（x=0〜824）を使っていて、**中に余白は無い**。

```
.factory-svg-wrap svg{ width:100%; max-height:calc(100vh - 115px); }
```

**高さで頭打ちにしている**ため、横に広く縦が短い画面では高さが先に上限へ当たり、
絵が縮んだぶん左右に地色が残る（`preserveAspectRatio` の既定は中央寄せ）。
→ **中身を横に広げる／縦を詰める**と、絵が大きくなって余白も減る。

## 4. 高さが足りない（ここが一番の制約）

カードに入れたい項目（社長の指定）

```
A2  CT 90%                      稼働中     ← 達成率はライン名のすぐ右、状況は右端（2026-09-21 社長指示）
6MA-ステイ-E   11:16〜16:52                ← 加工中の品番と、その予定時間
▓▓▓▓▓▓▓░░░░░░░░░░
見込 18:44 ▼112分     ⚠ 未報告 65分
次: 18326-HL4M-A 17:42〜19:06
```
見出しの並びは `ライン名 → CT達成率 → （空き） → 稼働状況`。
達成率は品番ではなく**ラインの値**なので、ライン名のそばに置く。

5行必要。いまのカードは A/B が高さ82、**C が62**。
C を92まで高くすると、プレスD → 溶接 → 凡例 が順に下がり、**446に収まらない**。

**とる案（おすすめ）**
> 横に広がったぶんを使い、**見込みと未報告を同じ行に並べて 5行に収める**。
> 高さは A/B=82のまま、**C だけ 62 → 88**（プレスCの箱を 160 → 190、プレスD以下を30下げ、
> 溶接・組立SPを 94 → 64、凡例・技術を 68 → 58 に詰める）。

**とらない案**
> すべてのカードを100に。縦が破綻する。

## 5. 表示する中身と、その出どころ

| 表示 | 出どころ | 備考 |
|---|---|---|
| 稼働状況 | `lineAutoStatus()` | 済（v2026.09.21-5） |
| CT達成率 | `calcLineRate().ctRate` | **進捗ボードと同じ値**。個数の%はやめる |
| 加工中の品番 | `line.part` | |
| その予定時間 | 加工中jobの `start`〜`end` | |
| 見込み完了時刻 | `calcLineRate().estFinish` | 計画終了との差も出す |
| 次の品番と予定時間 | 次の未着手job | |
| **未報告** | 最後に実績を入れてから**60分**超 | `lastCountMin()` からの経過 |
| 個数 | **出さない**（社長指示） | |

未報告のしきい値（60分）は設定から変えられるようにする。
