# 書き込み用GASの作り方（15分・既存のGASはさわりません）

H-Hub の 品質チェック →「システム入力待ち」→ 右の不良品報告ペインから、

- 在庫管理の「入力者」「入力日」を記入する
- 「在庫調整」「在庫投入」でプロセス管理を進める

この3つを動かすための準備です。**照合（不良品報告を横に出して三点を見る）だけなら、この準備は不要**で、
APIトークンを入れれば今すぐ使えます。

> ### なぜ新しく作るのか
> 既存の品質チェックGAS（記録の保存・読み込みに毎日使っているもの）に手を入れると、
> 直し損ねたときに品質チェックそのものが止まります。
> **別のGASを1つ作って、書き込みだけをそちらに任せる**ほうが安全です。
> 万一この新しいGASが動かなくても、記録も照合も今までどおり動きます。

---

## 全体の流れ

| | やること | 場所 |
|---|---|---|
| 手順1 | 書き込み用GASを作る | Google Apps Script |
| 手順2 | 「ウェブアプリ」として公開してURLを取る | Google Apps Script |
| 手順3 | kintoneのトークンに編集権限を足す | kintone |
| 手順4 | H-HubにURLを登録して接続テスト | H-Hub |

## 手順1　書き込み用GASを作る

1. ブラウザで **https://script.google.com/home** を開く
   （会社のGoogleアカウントでログインしていること）

2. 左上の **「＋ 新しいプロジェクト」** を押す

3. `コード.gs` の中身が最初から入っています（`function myFunction() {}` の3行）。
   **その3行を全部消す**
   - 編集エリアをクリック → `Ctrl + A`（全選択）→ `Delete`

4. このリポジトリの **`docs/kintone_write_gas.gs.example`** をメモ帳などで開き、
   **中身を全部コピー**して、空になった `コード.gs` に貼り付ける
   - ファイルの場所:
     `C:\Users\k--fu\Desktop\橋本_作業データ\hashimoto-press\docs\kintone_write_gas.gs.example`

5. 画面上の **「無題のプロジェクト」** を押して、名前を
   **`HHub kintone書き込み`** に変える

6. **フロッピーのアイコン（保存）** または `Ctrl + S` で保存

---

## 手順2　ウェブアプリとして公開する

1. 右上の青い **「デプロイ」** → **「新しいデプロイ」**

2. 左上の **歯車アイコン（種類の選択）** を押して、**「ウェブアプリ」** を選ぶ
   - ★ここを選び忘れるのが一番多い失敗です

3. 次の3つを設定する

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | `v1`（何でもよい） |
   | 次のユーザーとして実行 | **自分**（自分のメールアドレス） |
   | アクセスできるユーザー | **全員** ★重要 |

   > 「全員」にしないと、H-Hub（GitHub Pages）から呼べません。
   > このGASは**H-Hubから届いたトークンを使ってkintoneに中継するだけ**で、
   > GAS自体はトークンもデータも持ちません。

4. **「デプロイ」** を押す

5. 初回は **「アクセスを承認」** が出ます
   - Googleアカウントを選ぶ
   - **「このアプリは確認されていません」** と警告が出たら、
     **「詳細」** → **「HHub kintone書き込み（安全ではないページ）に移動」** を押す
     （自分で作ったスクリプトなので問題ありません）
   - **「許可」** を押す

6. **ウェブアプリのURL** が表示されます。
   `https://script.google.com/macros/s/AKfyc........../exec` の形です。
   **「コピー」を押して控えてください。** これを手順4で使います

   > あとから見たいときは「デプロイ」→「デプロイを管理」で確認できます

---

## 手順3　kintoneのトークンに編集権限を足す

1. kintone →**★不良品報告**（アプリID 31）を開く

2. 右上の **歯車** → **「アプリの設定」**

3. **「設定」タブ** → **「APIトークン」**

4. すでに照合用に作ったトークンがあるはずなので、その行の権限にチェックを足す

   | チェック | 何のため |
   |---|---|
   | レコード閲覧 | 照合（もう入っているはず） |
   | **レコード編集** | 入力者・入力日の記入 |
   | **ステータス変更** | 在庫調整・在庫投入を進める |

5. **「保存」** を押す

6. ★**画面右上の「アプリを更新」を押す**
   - これを押さないと権限が反映されません。**一番多い失敗です**

---

## 手順4　H-Hubに登録して確認する

1. H-Hub →**品質チェック** → 赤い「システム入力待ち」バーを押す

2. **「⚙ 不良品報告の設定」**

3. **「書き込み用GASのURL」** に、手順2でコピーしたURLを貼り付ける

4. **「🔌 接続テスト」** を押す
   - **✓ つながりました** と出れば成功
   - つながらない場合は下の「うまくいかないとき」へ

5. **「入力者の名前」** に、在庫管理へ記入する名前を入れる
   - その欄がユーザー選択なら、表示名ではなく**kintoneのログイン名**

6. **「保存して照合」** を押す

これで、右ペインの
「✓ 在庫管理に記入」「▶ 在庫調整」「▶ 在庫投入」が使えるようになります。

---

## 最初の1件は、必ず確認しながら

1. 不良品報告が1件だけ出ている品番を選ぶ
2. 三点（不具合数量・廃棄数量・合格数量）をそれぞれ押して ✓ を付ける
3. 「✓ 在庫管理に記入」→ 確認画面の数字が合っているか読んでから OK
4. **kintoneを開いて、入力者と入力日が入っているか自分の目で見る**
5. 合っていたら「▶ 在庫調整」へ進む

書き込みは毎回、内容を出してから実行します。取り消しはH-Hubからはできないので、
最初の数件はkintone側でも確かめてください。

## うまくいかないとき

| 症状 | 原因と直し方 |
|---|---|
| 接続テストが「つながりません」 | デプロイの**「アクセスできるユーザー」が「全員」**になっていない。デプロイ → デプロイを管理 → 鉛筆 → 直して「デプロイ」 |
| 「知らないaction」と出る | 貼り付けが途中で切れている。`docs/kintone_write_gas.gs.example` を**もう一度全部**コピーし直す |
| 記入で `403 GAIA_NO01` | トークンに**レコード編集**の権限がない。または kintone で**「アプリを更新」を押していない** |
| 進めるで `400 GAIA_IL26` | アクション名が違う。kintone → アプリの設定 → **プロセス管理**でアクション名を確認し、⚙設定の「アクション①／②」に同じ文字列を入れる |
| 進めるで `400 GAIA_IQ11` | いまのステータスからそのアクションは実行できない（順番が違う） |
| 記入で `400 CB_VA01` | 「入力者」がユーザー選択の欄。設定の「入力者の名前」を**kintoneのログイン名**に直す |

## コードを直したとき（今後）

`docs/kintone_write_gas.gs.example` を更新したら、GAS側にも貼り直しが要ります。

1. GASのコードを貼り替えて保存
2. **「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」**

★「新しいデプロイ」ではなく**既存のデプロイを編集**すること。
新規にするとURLが変わり、H-Hub側の設定も入れ直しになります。
