# kintone → Slack 個人あて通知　設定手順（2026-11-21）

## 何を変えたか

これまで、kintone の期限管理（App77）に登録すると Slack の **#基準遵守手当bot**
に投稿されていましたが、**担当者の名前が字で書いてあるだけ**で、本人のスマホは
鳴りませんでした。苦情・不適合報告書（App45）にいたっては**通知そのものが
ありませんでした**。

今回、次の2つを足しました。

| | いつ | どこへ |
|---|---|---|
| **期限管理（App77）** | 新規登録したとき | チャンネルに投稿（担当者を**メンション**）＋**担当者本人へDM** |
| | 完了報告を押したとき | チャンネルに投稿＋**依頼者（社長）へDM** |
| **苦情・不適合報告書（App45）** | 対策担当者か提出期限が**入った・変わった**とき | チャンネルに投稿（担当者をメンション）＋**担当者本人へDM** |

※ App45 は、保存のたびに鳴らないよう「担当者か期限が前と変わったときだけ」
送ります。担当者が空のあいだは何も送りません。

---

## 手順1　GASにスクリプトプロパティを2つ足す

GASのエディタ → 左の歯車（プロジェクトの設定）→ 下の「スクリプト プロパティ」
→「スクリプト プロパティを追加」。

| プロパティ | 値 |
|---|---|
| `SLACK_USER_MAP` | `橋本_作業データ\briefing_tools\slack_user_map.json` の**中身をまるごと**貼り付け |
| `SLACK_BOT_TOKEN` | `橋本_作業データ\maint_schedule\.env` の `SLACK_BOT_TOKEN=` の**右側（xoxb- で始まる文字列）**だけを貼り付け |

★この2つは**社外に出さない**ので、GASのプロパティに置きます。コードには書きません。
★どちらかを入れ忘れても**止まりません**。これまでどおりチャンネル投稿だけ行い、
　メンションやDMが出ないだけです。

**人が増えたり名前が変わったら** `slack_user_map.json` を直して、
`SLACK_USER_MAP` に貼り直してください。対応表に無い名前は、メンションにならず
**名前のまま**出ます（通知が止まることはありません）。

---

## 手順2　GASのコードを貼り替える

`基準遵守\kintone_gas_v3.js`（v3.9）の**全文**を GAS のエディタに貼って保存
→ **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**。

⚠**URLを変えないこと**。kintone 側が今のURLを呼んでいます。
　「新しいデプロイ」を作るとURLが変わってしまいます。

⚠GASの先頭にある `SLACK_WEBHOOK_NORMAL` / `SLACK_WEBHOOK_URGENT` は、
　このリポジトリの控えでは URL を伏せてあります。**いまGASに入っている本物の2行は
　消さずに残してください**（貼り替え前にその2行を控えておく）。

---

## 手順3　kintone App45 にカスタマイズJSを入れる

App45（苦情・不適合報告書）→ アプリの設定 → **JavaScript / CSSでカスタマイズ**
→ 「PC用のJavaScriptファイル」に `kintone_customize_app45.js` をアップロード
→ 保存 → **アプリを更新**。

⚠すでに別のJSが入っている場合は、**消さずに下に足して**ください。

---

## 手順4　動かしてみる

1. **App77**：テストで1件登録する（担当者＝自分の名前）。
   → #基準遵守手当bot に投稿され、**自分にDMが来れば成功**。
2. **App45**：どれか1件を開いて対策担当者を入れ直して保存する。
   → 同じく投稿＋DM。
3. うまくいかないときは、GASのエディタ →「実行数」またはログで
   `DM ◯◯ → 失敗 …` の行を見てください。原因が出ます。

## 担当者欄にチーム名が入っているとき（2026-11-21 社長が決定）

期限管理の担当者欄には、人の名前ではなく **「技術」「プレス」「品質」** と
チーム名が入っている件があります（55件中7件）。宛先はこう決めました。

| 担当者欄 | 宛先 |
|---|---|
| プレス | 仲田さん（本人へDM） |
| 品質 | 八木さん（本人へDM） |
| **技術** | **#技術 チャンネルへ投稿** |

対応表（`slack_user_map.json`）に書いてあります。人を増やす・変えるときも
ここに1行足すだけです。

⚠**#技術 に Kanagata-Bot を入れてください。** チャンネルに入っていないBotは
投稿できません（ログに `not_in_channel` と出ます）。
→ #技術 を開いて `/invite @Kanagata-Bot` と打つ。

## DMの届く場所（よくある問い合わせ）

Botからのメッセージは、サイドバーの「ダイレクトメッセージ」ではなく、
**一番下の「App」の中の Kanagata-Bot** に入ります。分けて並んでいるだけで、
中身は人からのDMと同じ1対1のダイレクトメッセージです。

通知も人からのDMと同じで、**未読バッジ・デスクトップ通知・スマホのプッシュ**が出ます。
鳴らない人は、本人のSlackで**アプリからの通知が切られていないか**を見てください。
