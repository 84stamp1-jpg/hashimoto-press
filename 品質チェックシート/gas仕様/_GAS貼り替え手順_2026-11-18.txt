なぜ直すのか
----------------------------------------------------------
H-Hubの「✓ 入力済みにする」を押し間違える人がいる、という社長の指摘（2026-11-18）。
・ボタンの上にマウスを置いたまま、画面が固まったときに何気なく押してしまう
・kintoneへ入力する前に押してしまう
・関係ない場所で押してしまう
押すとその行は入力待ちの一覧から消えるので、
★本人も周りも気づけない＝システムに入らないまま流れてしまいます。

H-Hub側（v2026.11.18-1／-2）では、
・1回押しただけでは確定しない（2回押し）
・入力済みにしたものを画面に札で残す
を入れました。この貼り替えで残りの2つが効くようになります。

(1)★「↶ 取り消す」── 押し間違いを「未」に戻せるようにする
    いまのGASには「済」を入れる口しかなく、戻す口がありません。
(2)★いつ・どの端末から押したかをシートに残す
    いまはM列に「済」の一文字しか残らず、押し間違いを追えません。
    U列＝システム入力 日時 ／ V列＝システム入力 端末 に書きます
    （見出しが空なら、GASが1回目に自動で入れます）。
    端末名は、H-Hubの呼び出しの設定で決めた「この端末の置き場所」です。

手順
----------------------------------------------------------
1. スプレッドシート「品質チェックシート記録」を開き、
   拡張機能 → Apps Script でエディタを開く（コード.gs が開きます）

2. 【A】Ctrl+F で   action === 'markAsInputted'   と検索する
   見つかった1行を、下の【新しい中身A】の2行で置き換える
   ※違いは  , payload.by  が付くことと、unmarkInputted の行が増えることだけです

3. 【B】Ctrl+F で   function markAsInputted   と検索する
   その行から、★function deleteRecord(rowNum, key) { の直前の行まで を
   すべて選んで削除する
   ※function deleteRecord の行は消さないこと

4. 消したところに、下の【新しい中身B】をそのまま貼る

5. 保存（Ctrl+S）

6. デプロイ →「デプロイを管理」→ 鉛筆マーク →
   バージョン「新バージョン」→ デプロイ
   ★「新しいデプロイ」を選ぶとURLが変わり、H-Hubから繋がらなくなります。
     必ず既存のものを鉛筆で編集すること

----------------------------------------------------------
貼り替えたあとの確認（3分）
----------------------------------------------------------
(1) H-Hubの品質チェック（入力待ち）を開き、1件「✓ 入力済みにする」を2回押す。
    → これまでどおり消え、上に札が出れば正常。
(2) その札の「↶ 取り消す」を2回押す。
    → 札が灰色になり「入力待ちに戻しました」と出て、一覧にその行が戻れば成功。
(3) シートを見る。
    → M列が「未」に戻り、U列に日時、V列に「取消 ○○（端末の置き場所）」が入っていれば成功。
(4) 日別一覧の明細（✏️🗑️の並び）に
    「システム入力 済（11/18 07:23　Aライン）」と出ていれば成功。
    その横の「↶ 取り消す」からも戻せます（こちらも2回押し）。

※ 貼り替える前は「↶ 取り消す」が失敗します（GASに口が無いため）。
   そのときは、これまでどおり記録シートのM列を手で「未」に戻してください。
※ 端末の置き場所を決めていないPCは、V列が空のまま入ります。
   右下の ⚙ 設定 →「この端末の置き場所」で決められます。

function markAsInputted(rowNum, key, by) {
  try {
    var sheet = getOrCreateSheet().getSheetByName(SHEET_NAME);
    var f = resolveRow_(sheet, rowNum, key);
    if (!f.ok) return f;
    setInputtedStamp_(sheet, f.row, '済', by);
    SpreadsheetApp.flush();
    return { ok: true, row: f.row, moved: !!f.moved };
  } catch(e) { return { ok: false, err: e.message }; }
}

// ★入力済みを取り消す（2026-11-18 社長指示）
//   「✓ 入力済みにする」を押し間違える人がいるため、H-Hubから「未」に戻せるようにした。
//   いつ・どの端末から取り消したかも残す。
function unmarkInputted(rowNum, key, by) {
  try {
    var sheet = getOrCreateSheet().getSheetByName(SHEET_NAME);
    var f = resolveRow_(sheet, rowNum, key);
    if (!f.ok) return f;
    setInputtedStamp_(sheet, f.row, '未', by ? ('取消 ' + by) : '取消');
    SpreadsheetApp.flush();
    return { ok: true, row: f.row, moved: !!f.moved };
  } catch(e) { return { ok: false, err: e.message }; }
}

// M列(13)＝システム入力（済／未）、U列(21)＝いつ押したか、V列(22)＝どの端末から
// ★「済」の一文字しか残らないと、誰がいつ押したのか分からず、押し間違いを追えない。
//   列は A〜T(20) まで使っているので、その右の2列に足す（見出しも無ければ入れる）。
function setInputtedStamp_(sheet, row, val, by) {
  sheet.getRange(row, 13).setValue(val);
  sheet.getRange(row, 21).setValue(Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd HH:mm'));
  sheet.getRange(row, 22).setValue(String(by || ''));
  var h = sheet.getRange(1, 21, 1, 2).getValues()[0];
  if (!h[0]) sheet.getRange(1, 21).setValue('システム入力 日時');
  if (!h[1]) sheet.getRange(1, 22).setValue('システム入力 端末');
}
