==========================================================
 橋本工業 総務・経理AIシステム  ファイル一式
==========================================================

【これは何？】
レシート・伝票をスマホ/スキャナで撮影 → Google Vision API で文字を
自動読み取り → 勘定科目を自動振り分け → 弥生会計用CSVに出力する仕組み。
経理担当者は「ブラウザでWebアプリを開いてボタンを押すだけ」で使える。

----------------------------------------------------------
【ファイルの役割】
----------------------------------------------------------
01_setup_drive_sheets.gs … 初期セットアップ（最初に1回だけ実行）
                            Driveのフォルダ構成と管理表(5シート)を自動生成
02_ocr.gs                 … レシート画像/PDFをOCRし「未処理」シートへ記録
03_categorize.gs          … 科目マスタを参照して勘定科目を自動振り分け
04_webapp.gs              … 実務用Webアプリのサーバー側処理
index.html                … 実務用Webアプリの画面（見た目）

※これら5ファイルは「すべて1つのGASプロジェクト（総務経理_メイン）」の
  中に入れて使う。バラバラの別プロジェクトではない。

----------------------------------------------------------
【動かす場所】
----------------------------------------------------------
・Googleアカウント：総務専用の新規アカウント（既存システムと完全分離）
・GASプロジェクト名：総務経理_メイン  （script.google.com）
・GCPプロジェクト：keiri-ocr（Cloud Vision API 有効化済み）
・APIキー：GASのスクリプトプロパティ VISION_API_KEY に保存
　　　　　 （コードには直書きしない方針）

----------------------------------------------------------
【日々の使い方（経理担当者）】
----------------------------------------------------------
1. レシートをスマホのGoogleドライブ「スキャン」で撮影
   → 保存先「総務_経理システム/01_レシート投入箱」
   （またはスキャナでフォルダへ。1レシート＝1ファイル）
2. WebアプリのURLを開く
3. 「①OCR実行」→「②自動振り分け」を押す
4. 「要確認リスト」に出たものを画面で修正→「確定」
   （不要なものは「🗑削除」）
5. （Phase3完成後）「弥生CSV出力」で弥生取込用CSVを書き出す

----------------------------------------------------------
【コードを修正したとき】
----------------------------------------------------------
・.gsやindexを直したら、GASエディタで貼り替え＆保存(Ctrl+S)。
・Webアプリに反映するには「再デプロイ」が必要：
   デプロイ → デプロイを管理 → 鉛筆(編集) → バージョン:新バージョン → デプロイ
   （URLは変わらない）

----------------------------------------------------------
【スプレッドシートの各シート】
----------------------------------------------------------
未処理     … OCR結果の一時保管
仕訳候補   … 科目振り分け済み（OK分）
確認待ち   … 人の判断が必要なもの（科目不明・金額/日付読めない・高額）
完了済み   … 弥生に出力したもの
科目マスタ … 振り分けルール（キーワード→勘定科目）※ここを編集して調整
店名補正   … 店名の誤読を正しい名前に固定（自動作成）

----------------------------------------------------------
【開発状況】
----------------------------------------------------------
Phase1（OCR基盤）           … 完了
Phase2（自動振り分け＋Webアプリ）… ほぼ完了
Phase3（弥生CSV出力・月次自動化）… これから
  ※弥生の正式なCSVインポート仕様（列の並び）を確認してから実装

全体仕様の詳細は、デスクトップの CLAUDE.md / プロジェクト指示書を参照。
