# 橋本工業 生産計画システム — Claude Code 引き継ぎ

## プロジェクト概要
プレス部門の週間生産計画を自動生成するシステム。
- 入力: 作業予定一覧.xlsx（生産管理システムからエクスポート）+ 製品マスタ.xlsx
- 出力: 週間ガントチャート Excel（1日1シート・15分刻み）
- 制約: 出勤13名上限・設備競合・休憩時間込み

## ファイル構成
```
production_plan/
├── CLAUDE.md              ← このファイル（Claude Code の指示書）
├── generate_plan.py       ← メインスクリプト
├── requirements.txt       ← pip install -r requirements.txt
├── .env.example           ← Slack設定テンプレート
├── input/
│   ├── 作業予定一覧.xlsx  ← 毎回上書き（生産管理システムからエクスポート）
│   └── 製品マスタ.xlsx    ← 固定（シート「マスタ本体」+「加工パターンテーブル」）
└── output/                ← 生成された計画書が入る
```

## 基本の使い方
```bash
# 今日から1週間分の計画を生成
python generate_plan.py

# 日付を指定
python generate_plan.py --date 2026-04-01

# Slackに投稿（.envにトークン設定が必要）
python generate_plan.py --slack

# 出勤人数を変える（デフォルト13名）
python generate_plan.py --workers 12
```

## 製品マスタの構造（重要）

### シート「マスタ本体」
- ヘッダーは3行構造（行1:グループ名、行2:列名、行3:説明）
- データは5行目から
- 主要列: 品番、工程(ライン)、段取時間(分)、段取人員(名)、取数(個)、
         標準時間1(個/h)、標準作業員(名)、最小作業員(名)、人員削減タイプ、
         設備1〜4、代替設備リスト

### シート「加工パターンテーブル」
- ヘッダーは2行構造（行1:タイトル、行2:説明文、行3:列名）
- データは4行目から
- 複数設備品番の「設備の組み合わせ×人員→出来高」を登録
- 列: No、品番、パターン名、使用設備1〜5、作業員(名)、段取時間(分)、
     段取人員(名)、出来高(個/h)、取数(個)、優先度、備考

## スケジューリングルール（確定）

### 休憩時間（全品番共通）
- 10:00-10:10（10分）
- 12:10-12:50（40分）
- 14:50-15:00（10分）
- 17:00-17:10（10分）
- 始業8:00 終業19:00 実稼働590分

### 人員制約
- 同時稼働 ≤ MAX_W名（デフォルト13名）
- 段取中は段取人員、加工中は作業員を別々にカウント
- **重要**: 加工時間全体（ws〜we）で人員チェック。1分後だけでは不十分

### 設備ルール
- 段取開始 = 設備の専有開始（他品番は使用不可）
- 設備解放 = 加工完了
- 段取のみ先行可（全品番共通）
- 段取後に他の設備で別品番を加工可（同設備は不可）
- 段取後の加工待機: 他品番がその設備を使うまで無制限

### パターン選択
1. 加工パターンテーブルに登録がある品番 → 優先度順に設備×人員チェック
2. 登録がない品番 → マスタ本体の設備1〜4 + 標準時間1 + 標準作業員

### 出来高計算
- std1h = 標準時間1(個/h) × 取数(個)  ← 取数込みの時間あたり出来高
- ppm = std1h / 60  ← 1分あたり生産数
- 今日の生産数 = min(残数, work_in(ws, we) × ppm)
- マスタ未登録品番 → 作業予定一覧の加工(M)（分/個）から計算: ppm = 1/加工(M)/60

### 優先順位
納期超過日数が大きい順 → 当日納期 → 将来納期 → 工順

## ガントチャートレイアウト仕様
- タイムライン: 15分刻み（44スロット）
- 1ジョブ = 2行構成
  - 上行: 品番（太字）/ 指示数 / 段取員 / 時間
  - 下行: 品名（小字）/ 本日生産（太字）/ 作業員
- 段取バー: 黄色（上行濃/下行淡）
- 加工バー: 工程色（プレスA=青/B=橙/C=緑/D=水色）
- 人員サマリー行: 緑=13名フル / 黄=10〜12名 / 橙=手待ち
- マスタ未登録品番: ★マーク + 橙色テキスト + 警告行

## 既知の課題・メモ
- 6QPFX-0515/0516-A-00-00: マスタ未登録。設備不明のため仮想設備C_MISCで計画
- 62133/18219/18220/18181（A設備系）: 作業予定一覧の投入人数が空欄 → 1名として計算
- 設備なしジョブ: 工程名から仮想設備（B_MISC, C_MISC等）を割り当て
- week_plan.pkl はセッション終了で消える → 毎回 generate_plan.py を再実行

## よくある変更依頼と対応箇所
| 変更内容 | 対応箇所 |
|---------|---------|
| 休憩時間の変更 | BREAKS定数 |
| 始業・終業時刻の変更 | WS / WE定数 |
| 出勤人数の変更 | --workers オプション or MAX_W定数 |
| ガントの色変更 | PAL辞書 |
| 列の追加・削除 | build_sheet()の固定列部分 |
| Slackチャンネル変更 | .envのSLACK_CHANNEL |
| マスタの列名が変わった場合 | load_data()の列名マッピング部分 |

## 開発履歴（重要な設計変更）
1. 標準時間1の単位: **個/h**（秒/個ではない）
2. 段取と加工の人員は別々にカウント（peak_wでまとめない）
3. 加工員チェックは加工時間**全体**で行う（1分後だけでは超過する）
4. 設備なし品番は工程別仮想設備を割り当て
5. パターンテーブル: 設備の組み合わせ×人員→出来高の複数パターン対応
